# Video demo landing

Set `NEXT_PUBLIC_DEMO_VIDEO_URL` in the Vercel project environment, then redeploy. Supported URLs: YouTube watch/share URLs, public Vimeo numeric links, and HTTPS `.mp4` or `.webm` files. The final section shows a truthful pending placeholder until a valid URL is configured. Videos load on demand without autoplay. This setting is public; do not put API keys in it.
