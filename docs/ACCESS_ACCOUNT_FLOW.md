# SekolaPro — Akses anggota & wali kelas

Akun login dibuat oleh kepala sekolah/pemilik, terikat ke satu sekolah dan ke satu profil SDM; Viewer tidak dihitung sebagai presensi pegawai. Hak akses ditentukan per role dengan batasan backend. Wali kelas punya opsi tautkan akun guru atau catat nama tanpa akun; bisa diedit setelah kelas dibuat. Akun nonaktif tidak berhak mengakses data dan tidak dihapus dari riwayat presensi. Gunakan layanan provisioning di backend menggunakan kredensial server saja dan tidak pernah meminta service-role key di browser.
